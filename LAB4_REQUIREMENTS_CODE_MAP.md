## Important distinctions for the oral demonstration

- A repository interface is not an implementation class written by you; Spring Data provides the implementation.
- @MappedSuperclass is not @Entity: it shares mappings but does not create a separate contact_person table.
- The owning side carries the FK: Vehicle.depot and Delivery.customer; mappedBy names refer to Java fields.
- NULL driver_id is permitted; UNIQUE driver_id prevents one driver being referenced twice.
- The JPA model matches the SQL schema, but tables themselves are created by schema.sql.
- The one-to-one vehicle/driver association has application-side checking plus a database constraint. The database constraint is the final safeguard under concurrency.
- @Modifying runs a bulk UPDATE; clearAutomatically prevents stale managed values in the same persistence context.
- PostgreSQL integration tests are disabled without RUN_PG_INTEGRATION_TESTS=true and must not be counted as executed in the standard run.
- Routing/optimization algorithms and REST endpoints are future labs, not required in this lab.
- Coordinates are presently WGS84 latitude,longitude strings, not a spatial database type.
